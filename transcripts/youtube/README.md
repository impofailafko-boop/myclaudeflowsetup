## Quick Start

Due to network restrictions in the automated environment, transcripts need to be downloaded locally.

### Option 1: Automated Download (Recommended)

Run the provided Python script on your local machine:

```bash
# Install the required library
pip install youtube-transcript-api

# Run the download script
python3 download_transcripts.py
```

The script will automatically download all 12 video transcripts in 3 formats (.md, .txt, .json) and update this README.

### Option 2: Manual Download

If you prefer, you can manually download transcripts from YouTube or use other tools.
